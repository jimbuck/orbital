## Anywhere in the window

These work even with focus inside a terminal. Orbital catches them before the
terminal sees the key.

| Shortcut | Action |
|---|---|
| Ctrl+Shift+P | Command palette (commands) |
| Ctrl+Shift+O | Command palette (files, commands, worktrees, tasks) |
| Ctrl + / Ctrl = | Zoom in |
| Ctrl - | Zoom out |
| Ctrl 0 | Reset zoom |
| Ctrl+Shift+R | Reload the window |

## Outside a terminal

| Shortcut | Action |
|---|---|
| Ctrl+P | Go to file (the palette's mixed view). Inside a terminal, Ctrl+P stays with your shell. |
| Esc | Close the open dialog |

## Command palette

| Shortcut | Action |
|---|---|
| ↑ / ↓ | Move the selection |
| Home / End | First / last result |
| Enter | Run or open the selection |
| `>` `/` `@` `#` | Switch to commands, text, worktrees or tasks |

## Terminals

| Shortcut | Action |
|---|---|
| Ctrl+C | Copy the selection. With nothing selected it sends an interrupt, as usual. |
| Ctrl+V | Paste. A clipboard image is saved to a scratch file and its path pasted, so agents can read screenshots. |
| Right-click | Paste |
| Click a URL | Open it in an in-app browser tab |
| Ctrl+click a URL | Open it in your system browser |

## Editor

| Shortcut | Action |
|---|---|
| Ctrl+S | Save the active file |
| Ctrl+F | Find in file |
| Ctrl+H | Find and replace |
| Enter / Shift+Enter | Next / previous match (in the find box) |
| F3 / Shift+F3 | Next / previous match, while typing in the file |
| Alt+C / Alt+W / Alt+R | Toggle match case / whole word / regex (in the find widget) |
| Enter | Replace the current match (in the replace box) |
| Ctrl+Alt+Enter | Replace all matches |
| Esc | Close the find widget |
| Ctrl+Shift+[ / Ctrl+Shift+] | Fold / unfold the block at the caret |
| Tab | Indent (two spaces) |

## Git panel

| Shortcut | Action |
|---|---|
| Ctrl+Enter | Commit (in the message box) |

## Commit history

| Shortcut | Action |
|---|---|
| ↑ / ↓ | Walk the commit list |

## Search tab

| Shortcut | Action |
|---|---|
| Enter | Open the selected hit |
| Delete / Backspace | Strike off the selected hit |
