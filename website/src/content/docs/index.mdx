<p class="ob-section-label">Flight systems</p>
<h2 class="ob-section-title">Everything between "brief the agent" and "merge the branch"</h2>

<section class="ob-features">
  <article class="ob-feature" data-index="01">
    <span class="glyph">◫</span>
    <h3>Isolated Flights</h3>
    <p>
      Every stream of work gets its own git worktree, branch, terminals, and pane
      layout — created in one click, with your <code>.env</code> files synced in
      automatically. Agents never trample each other's changes.
    </p>
  </article>
  <article class="ob-feature" data-index="02">
    <span class="glyph">◉</span>
    <h3>Know who needs you</h3>
    <p>
      Terminals report their status live. When an agent blocks on a permission
      prompt, the rail pulses, the title bar shows a banner, the taskbar icon is
      badged — and typing into the agent clears it instantly.
    </p>
  </article>
  <article class="ob-feature" data-index="03">
    <span class="glyph">⌥</span>
    <h3>A cockpit, not just terminals</h3>
    <p>
      Split panes of terminals, in-app browser previews, and an editor with
      syntax-highlighted diffs and image rendering — plus a full git panel to
      review, commit, and push finished work.
    </p>
  </article>
  <article class="ob-feature" data-index="04">
    <span class="glyph">▸_</span>
    <h3>Agents are first-class</h3>
    <p>
      The <code>orbital</code> CLI lets agents set status, file and progress
      tasks on the shared board, open tabs, and register dev servers — so the
      cockpit always reflects reality.
    </p>
  </article>
</section>
