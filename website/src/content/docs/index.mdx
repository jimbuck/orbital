<p class="ob-section-label">Flight systems</p>
<h2 class="ob-section-title">Everything between "brief the agent" and "merge the branch"</h2>

<section class="ob-features">
  <article class="ob-feature" data-index="01">
    <span class="glyph">◫</span>
    <h3>Isolated worktrees</h3>
    <p>
      Every stream of work gets its own git worktree, branch, terminals, and pane
      layout, created in one click with your <code>.env</code> files and agent
      config copied in. Agents never trample each other's changes.
    </p>
  </article>
  <article class="ob-feature" data-index="02">
    <span class="glyph">◉</span>
    <h3>Know who needs you</h3>
    <p>
      Terminals report their status live. When an agent blocks on a permission
      prompt, the rail pulses, the title bar shows a banner, the taskbar icon
      glows and flashes. Typing into the agent clears it.
    </p>
  </article>
  <article class="ob-feature" data-index="03">
    <span class="glyph">⌥</span>
    <h3>A cockpit, not just terminals</h3>
    <p>
      Split panes of terminals, in-app browser previews, and an editor with
      highlighted diffs, markdown and mermaid previews, plus a full git panel
      with commit history to review, commit, and push finished work.
    </p>
  </article>
  <article class="ob-feature" data-index="04">
    <span class="glyph">▸_</span>
    <h3>Your harness, at full power</h3>
    <p>
      Orbital runs the real interactive CLI, so slash commands, hooks, MCP
      servers and permission modes all work. Agent tabs pick up their
      conversation again after a restart.
    </p>
  </article>
  <article class="ob-feature" data-index="05">
    <span class="glyph">⌘</span>
    <h3>Keyboard to anywhere</h3>
    <p>
      <kbd>Ctrl+Shift+P</kbd> reaches files in every worktree, commands, tasks
      and worktrees. Content search runs across checkouts in a tab you can
      work through hit by hit.
    </p>
  </article>
  <article class="ob-feature" data-index="06">
    <span class="glyph">◐</span>
    <h3>Workspaces, your way</h3>
    <p>
      Keep work and personal repos in separate windows, each with its own theme,
      accent colour and agent profiles. Twenty themes, from Dracula to
      Solarized, colour the terminal and editor too.
    </p>
  </article>
</section>

<p class="ob-section-label" style="margin-top:4rem">Instrumentation</p>
<h2 class="ob-section-title">Your agents talk back</h2>

<p class="ob-intro">Every terminal has the <code>orbital</code> CLI on its path. Agents use it to report status, claim and file tasks, and register dev servers, so the cockpit always reflects what's actually happening. Orbital teaches it to them with a per-launch briefing, an Agent Skill, and an <code>AGENTS.md</code> block for Codex. <a href="/orbital/agents/overview/">Docs for agents →</a></p>

  <div class="ob-shot-bar" aria-hidden="true"><i></i><i></i><i></i><span>worktree checkout-flow — nebula-shop</span></div>
