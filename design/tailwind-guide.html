03

Radius, spacing & elevation

Radius scales with the element's size — chips are tight, modals are soft. Spacing is a plain 1px–based rhythm; lean on Tailwind's default 4px scale and the arbitrary values below where the design is denser than the scale.

{{ r.tw }}
{{ r.use }}
Elevation
Flat surfaces only — depth comes from layering greys, not big shadows. The one real shadow is the modal: shadow-[0_24px_70px_rgba(0,0,0,.6)]. Glow dots use shadow-[0_0_8px_…] in the status hue.
Density
This is a desktop IDE — tighter than web defaults. Card padding p-3, list rows px-2.5 py-2, icon buttons h-7 w-7. Minimum interactive target ≈ 28px.
04

Tailwind setup

Drop this into your main CSS. It registers every token as a Tailwind utility namespace — bg-panel, text-muted, border-line-strong, rounded-card, animate-pulse-dot.

app.css 
/* Tailwind v4 — single CSS entrypoint */
@import "tailwindcss";

@theme {
  /* surfaces */
  --color-bg:        #0a0d12;
  --color-rail:      #0c1017;
  --color-bar:       #0b0f16;
  --color-pane:      #0d1118;
  --color-panel:     #11151d;
  --color-panel-2:   #141925;
  --color-elev:      #161b24;

  /* text */
  --color-text:      #e6ebf2;
  --color-text-2:    #cfd6e2;
  --color-text-3:    #aab2c0;
  --color-muted:     #8b95a6;
  --color-dim:       #7d8696;
  --color-faint:     #5b6473;

  /* lines & fills (white @ low alpha) */
  --color-line:        rgb(255 255 255 / 0.06);
  --color-line-2:      rgb(255 255 255 / 0.08);
  --color-soft:        rgb(255 255 255 / 0.05);
  --color-line-strong: rgb(255 255 255 / 0.12);
  --color-hover:       rgb(255 255 255 / 0.04);

  /* accent & status */
  --color-accent:    #4f8cff;   --color-blue:    #9cc0ff;
  --color-amber:     #e8b54a;   --color-amber-2: #e8c98a;
  --color-green:     #3ddc97;   --color-green-2: #6fe6b3;
  --color-red:       #ff6b6b;   --color-red-2:   #ff9a9a;

  /* diff */
  --color-diff-add:  #9fe9c6;
  --color-diff-del:  #ffb0b0;
  --color-diff-hunk: #7d9cff;

  /* type */
  --font-sans: "Hanken Grotesk", system-ui, sans-serif;
  --font-mono: "JetBrains Mono", ui-monospace, monospace;

  /* radius */
  --radius-chip:  5px;
  --radius-btn:   8px;
  --radius-card:  10px;
  --radius-col:   12px;
  --radius-modal: 14px;

  /* motion */
  --animate-pulse-dot: pulseDot 1.6s ease-in-out infinite;
  --animate-blink:     blink 1.1s step-end infinite;
}

@keyframes pulseDot {
  0%,100% { transform: scale(1);    opacity: 1;   }
  50%     { transform: scale(1.55); opacity: .45; }
}
@keyframes blink { 0%,48% { opacity: 1 } 49%,100% { opacity: 0 } }

@layer base {
  body { @apply bg-bg text-text font-sans antialiased; }
}

On Tailwind v3, move the same values into theme.extend.colors / fontFamily / borderRadius / keyframes / animation in tailwind.config.js — the class names come out identical. Spinners can drop the keyframe entirely and use the built-in animate-spin.

07

Branding & voice

Orbital's identity is its vocabulary and restraint. Keep the lexicon consistent and the chrome quiet.

Lexicon
{{ x.term }} {{ x.def }}
Voice
  • Terse and technical. Labels are 1–3 words.
  • Repo, branch, file and path names stay lowercase in mono.
  • Status speaks plainly: needs you, working, done.
  • No exclamation, no marketing tone inside the app.
Iconography
  • Use a single line-icon set (Lucide) at 14–16px, 1.5px stroke.
  • No emoji in product UI. Swap the placeholder glyphs (🌐, ▸) for real icons.
  • Status is carried by the colored dot, not an icon.
  • Color never decorates — a hue on screen always means a status.
Accessibility floor. Body text stays at text-3 or lighter on panel surfaces (≥ 4.5:1). Every interactive element gets focus-visible:ring-2 ring-accent/60 outline-none. Don't rely on dot color alone — pair it with the text label, as the cockpit does.
